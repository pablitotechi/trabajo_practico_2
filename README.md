# 🧑‍💻 FastAPI User Management API

Este es un proyecto básico de **API REST** desarrollado con [FastAPI](https://fastapi.tiangolo.com/), que permite **crear y obtener usuarios** en memoria.

## 🚀 Características

- Crear usuarios con nombre y correo electrónico
- Consultar todos los usuarios registrados
- Estructura basada en FastAPI
- Uso de modelos con Pydantic para validación de datos

---

## 🛠️ Tecnologías

- [FastAPI](https://fastapi.tiangolo.com/)
- [Uvicorn](https://www.uvicorn.org/) (como servidor ASGI)
- [Pydantic](https://docs.pydantic.dev/) (para validación de datos)
